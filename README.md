# Rincón Creativo

Página web estática, sencilla y responsive creada con HTML, CSS y JavaScript.

## Vista general

La página presenta un espacio creativo con:

- Sección principal con llamada a la acción.
- Navegación interna hacia las secciones de ideas, información y contacto.
- Tres tarjetas con formas de avanzar en un proyecto.
- Botón interactivo que muestra mensajes de inspiración aleatorios.
- Reloj analógico fijo en la esquina inferior derecha.
- Diseño adaptable para ordenador, tablet y móvil.

## Archivos

```text
Mi web/
├── index.html   # Estructura y contenido de la página
├── styles.css   # Estilos, colores y diseño responsive
├── script.js    # Interacciones y funcionamiento del reloj
└── README.md    # Documentación del proyecto
```

## Cómo abrir la página

No es necesario instalar dependencias ni usar un servidor. Abre `index.html` directamente en cualquier navegador.

También puedes abrir la carpeta en Visual Studio Code y usar una extensión como Live Server para disponer de recarga automática durante el desarrollo.

## Personalización

- Cambia los textos y enlaces en `index.html`.
- Modifica los colores y tamaños en las variables de `styles.css`.
- Añade o sustituye frases en el array `messages` de `script.js`.
- El reloj utiliza la hora local del navegador y actualiza sus agujas cada segundo.

## Tecnologías

- CSS3
- JavaScript
